# 训练存档清单

所有训练产生的 run 目录记在这里,一行一个。`logs\` 不进 git,所以这份清单是"哪台机器上有什么存档"的唯一记录。
新训练结束后加一行;把存档复制到另一侧的方法见 `stage0_commands.md` 第八节。

## 加一行要写什么

run 目录名、在哪台机器、轮数范围和存档数、用途(哪个阶段或哪个实验)、状态(保留 / 可删)。续训的写明从哪个 run 的哪个存档起。
